# Unique Mail Sender in Bulk

A secure, serverless web application that allows you to upload an Excel or CSV spreadsheet and generate highly customized emails for your clients. 

## How It Works
1. **100% Secure**: All processing happens directly inside your web browser. Your client database and email addresses are never sent to an external server.
2. **Dynamic Tags**: Use placeholder brackets matching your Excel columns (like `{Name}`, `{Amount}`, or `{Date}`) to instantly inject unique information into each email template.

## How to Use
1. Prepare an Excel file (`.xlsx` or `.xls`) or a `.csv` file.
2. Ensure the very first row contains clear headers (e.g., **Email**, **Name**, **Amount**).
3. Upload the file to the app.
4. Draft your subject line and email body using the format `{HeaderName}` wherever you want unique text to appear.
5. Click **Generate Email Queue**.
6. Click **Open Draft** next to any client to automatically open your local email provider (Gmail, Outlook, Apple Mail) with the personalized details filled out.
